# DAF landing setup

Public download page for the Diaspora Aid Foundation. The GitHub repo is `DeonHub/daf_landing_page` (the old `avatar` URL redirects here). This repository is public. Do not commit filled env files.

## Prerequisites

- Node.js 20

## Configure

```powershell
copy .env.example .env
npm install
```

## Run

```powershell
npm run dev
```
